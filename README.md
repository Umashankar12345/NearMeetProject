# NearMeetProject

## Overall Architecture
- **Frontend**: Android App (Kotlin - Jetpack Compose)
- **Backend API**: Node.js + Express
- **Database**: MongoDB

## Features
- User Authentication (Login / Signup)
- Home Screen (Nearby Events with Maps Integration)
- Location Features (Get current location, Filter events by distance)
- Notifications (Firebase Cloud Messaging)
- Create Event (Title, Description, Date & Time, Location)

## Smart Features
- Search events
- Distance filter
- Save/Favorite events
- Join event
- Upload event images
